02 / USE CASES

Kuupの活用例。

質問と回答のサンプルから、自分の目的に合う聞き方を見つけよう。

勉強文章作成プログラミングアイデア出し

勉強

理解してから、自分で解く。

説明を読んだあと、答えと理由を自分の言葉で伝えてみよう。

Kuupチャット会話例

理科の「電圧」と「電流」の違いを、水の流れにたとえて説明して。最後に確認問題を1問出して。

Kuup

水を押し出す力の差が電圧、水が流れる量が電流にあたります。同じ細さの管なら、圧力差が大きいほど水はたくさん流れます。

確認問題：同じ抵抗で電圧を上げると、電流はどうなる？

文章作成

言いたいことを、読みやすく。

相手との関係と希望の長さを指定すると、文面を整えやすくなります。

Kuupチャット会話例

提出物の締切を確認するメールを、失礼のない短い文にして。先生宛てで、件名もつけて。

Kuup

件名：提出物の締切について
お世話になっております。〇〇です。先日の提出物について、提出期限を確認したくご連絡しました。お手すきの際に教えていただけますと幸いです。

次の一言：「もう少し普段の話し方に近づけて」。

プログラミング

エラーの手がかりをつかむ。

関連するコードとエラー行を添えると、原因を絞り込みやすくなります。

Kuupチャット会話例

JavaScriptの「Cannot read properties of null」が出た。どこを確認したらいい？

Kuup

エラー行で何が null になっているかを確認しましょう。要素を取得するコードなら、セレクターがHTMLと一致するか、要素ができる前に実行していないかを順に調べます。

次の一言：「このHTMLとJSで、どちらの原因か一緒に確認して」。

アイデア出し

条件を決めて、発想を広げる。

時間、予算、人数など、先に条件を共有すると比較しやすくなります。

Kuupチャット会話例

文化祭の教室展示の案を3つ出して。来場者が5分以内で参加できて、材料費が安いもの。

Kuup

① 校内マップクイズ。校舎の一部を切り抜いた写真から場所を当てます。② お題くじの一筆アート。短い線をつなぎ、共同作品にします。③ 紙タワー対決。紙1枚でどこまで高くできるか競います。

次の一言：「準備時間と、混雑しにくさで比較して」。

うまく伝えるコツ

「何をしてほしいか」「誰に向けたものか」「どんな形で受け取りたいか」をひとつずつ添えてみよう。たとえば、メールなら「先生宛て」「欠席の連絡」「件名を含めて100字前後」と具体的にすると、直したい箇所を見つけやすくなります。
