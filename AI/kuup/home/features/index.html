01 / FEATURES

Kuupでできること。

会話を深める、作業を進める、資料を読み解く。目的に合わせてKuupの機能を使い分けよう。

AIチャット

疑問を解いたり、文章を整えたり。日本語で会話しながら、答えを自分に合う形に深掘りできます。

質問を「中学生向けに、具体例つきで」のように絞ると、ほしい説明に近づきます。回答を受け取ったら「最後の部分をもう少し詳しく」など、会話の流れで調整できます。

たとえば「電流と電圧の違いを、水の流れにたとえて教えて」。

Kuup Ultra

複数の手順が必要な作業にはUltra。Agentに依頼すると、作業の進み具合を画面で追えます。

比較表の作成や、いくつかの工程がある制作に向いています。依頼時に完成形と条件を伝え、途中の作業ログや生成物を確認できます。対応する生成物はプレビューで確認できます。

たとえば「文化祭の案内ページを作って。日時、会場、持ち物がスマホでもすぐ分かる構成で」。

Memory

メモリ共有を有効にすると、会話で共有した好みや背景を必要なときにKuupが参照します。説明を繰り返す手間を減らせます。

長く続くプロジェクトや、回答の言葉づかいに好みがあるときに役立ちます。設定の「Kuup Memory Core」で記憶を確認・修正・削除でき、メモリ共有をOFFにできます。

たとえば「コードの例はJavaScriptがいい。変更した理由も短く説明して」。

ファイル・画像

入力欄の「＋」から写真やファイルを添付して、文章や画像を見ながら相談できます。

資料は「2ページ目の結論を3点に要約」のように、見てほしい場所と出力形式を添えてください。添付できる形式や容量は、選択中の機能やファイル選択画面で確認できます。

たとえば「このスクリーンショットに出ているエラーの意味と、最初に調べる場所を教えて」。
