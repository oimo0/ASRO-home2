ASRO-I

サービスの裏側まで、
自分たちの手で。

ASRO-iは、ASROのサービスとAIを支えるインフラ領域です。

自分たちで運用するサーバーを中心に、Webサービス、データ、ローカルAIの実行環境を整備。外部の基盤も組み合わせながら、ASROを動かす土台を育てています。

01 / COMPUTE

実行基盤

WebサービスとローカルAIが動く環境を整備。使える計算資源の中で、安定した動作を目指します。

02 / OPERATIONS

運用と監視

稼働状況の確認、バックアップ、復旧手順の整備。つくったサービスを、継続して運用するための仕組みを改善します。

03 / SECURITY

守る仕組み

認証・権限・公開範囲を点検し、問題を見つけて修正。サービスの成長とともに、セキュリティの改善を続けます。

SECURITY / CONTINUOUS IMPROVEMENT

ASRO Security

サービスと基盤を守るための点検・修正・検証を継続。ASRO-iの運用と連携しながら、セキュリティの対策を強化しています。
